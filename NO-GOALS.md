# Qué NO es este proyecto

- No es una herramienta para instalar ni un producto.
- No genera mensajes de commit ni sugiere cambios.
- No analiza la calidad del código ni detecta vulnerabilidades.
- No busca superar el estado del arte publicado.
- No entrena ningún modelo grande desde cero con datos masivos: eso está fuera del
  alcance de un portátil y no es el punto.

Ver [`DESIGN.md`](DESIGN.md) para qué sí es.
